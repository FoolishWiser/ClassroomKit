# 命令行与 HTTP API

日常操作都在桌面主界面里；这份文档给脚本、自动化和排障用。所有命令都在 `C:\Program Files\ClassroomKit\ClassroomKit.Agent.exe` 下执行。

## 命令行

```text
ClassroomKit.Agent.exe            常驻守护 + 托盘 + 桌面主界面
--tray                            只起托盘，不弹主界面（开机自启任务用它）
--ensure                          确保守护在跑且热点开着（在跑则秒退；给 ClassIsland 调用）
--on / --off                      开 / 关热点策略
--status                          打印状态 JSON
--diagnose                        一键自检（JSON；0.8.3 起含 selfheal 项）
--probe                           收集本机能力（JSON），评估能不能用
--fix-peers                       提权写 WifiMaxPeers 并重启 icssvc
--install-task / --uninstall-task 注册 / 删除登录自启任务
--install-service / --uninstall-service 注册 / 删除 SYSTEM 护航任务（hosts 与静默升级）
--hosts-status / --hosts-refresh / --hosts-restore  GitHub 加速 hosts 的状态、刷新、还原
--uplinks                        列出本机所有网卡，说明会挑哪块开热点
--save-board                     保存板书（默认不关 ClassInX、默认按课表改名）
--save-board --close             保存后关闭 ClassInX（先等保存窗口消失）
--save-board --no-name           保存但不按课表改名
--save-board --no-launch         不自动启动 ClassInX（没开就直接报错）
--save-classin-board             老用法：保存并关闭 ClassInX
--lesson-status                  课表快照与提醒状态（JSON）
--lesson-reminder-test           跑一次自动保存判定；--show 只给迁移提示（1.0 起不再弹提醒窗）
--uninstall                      卸载自己（MSI 装的走 msiexec /x；绿色版自己删目录）
--uninstall --purge-data         连 C:\ProgramData\ClassroomKit（配置/日志）一起删
--panel                          兼容旧脚本：提示网页面板已移除并退出（退出码 2）
--rotate-token                   重置本地 API 令牌（ClassIsland 插件需重填）
--conflict-check                 检查板书软件是否全屏冲突（JSON；无冲突退出码 8）
--conflict-preview               在屏幕上预览一次冲突提示窗
--probe-classin                  重新探测 ClassInX 保存对话框的坐标并写入 ui-recipe.json
--check-update                   检查 GitHub 上有没有新版本（只查不装）
--update                         下载并安装新版（--dry-run 只检查不安装）
--version
```

## HTTP API

ClassIsland 插件与脚本都走 `http://127.0.0.1:36037`。全部要令牌：`?t=...` 或请求头 `X-Token`。

0.8.2 起不再提供网页面板：除 `/api` 外一律返回 404（包括 `/` 与 `/index.html`），令牌校验只对 `/api` 生效。

0.8.3 起 `GET /api/state` 增加 `selfHeal`（自动修复开关、累计次数、最近一次时间/结果/原因）；`POST /api/action` 的 `repair-network` 可手动检查并修复。

1.0 起 `GET /api/state` 增加 `boardAutoSave`（自动保存阶段、剩余秒数、科目、截止时间）；新增 `GET /api/board-autosave` 与 `POST /api/board-autosave`，旧的 `board-reminder-preview` 转为预览自动保存倒计时，`board-reminder-snooze` 返回 410。

| 方法与路径 | 说明 |
| --- | --- |
| `GET /api/state` | 完整状态：热点、上行、课表、板书、hosts、升级、冲突、自我修复 |
| `GET /api/lesson` | 课表快照 + 自动保存判定（没人推送过就 `available=false`） |
| `POST /api/lesson` | ClassIsland 插件推送课表快照；`{"action":"clear"}` 清空 |
| `GET /api/clients` | 在线设备列表 |
| `GET /api/logs?take=100` | 最近日志 |
| `GET /api/health` | 存活探针 |
| `GET /api/uplinks` | 本机所有网卡 + 自动选中的那块 + 选择理由 |
| `GET /api/board` | 板书：ClassInX 是否在跑、保存目录、冲突冷却状态 |
| `GET /api/board-autosave` | 课后自动保存状态（阶段、剩余秒数、科目、截止时间） |
| `POST /api/board-autosave` | `action=preview` 预览 15 秒倒计时，`action=cancel` 取消本轮 |
| `GET /api/hosts` | hosts 护航状态 |
| `GET /api/update` | 升级状态（`POST` + `action=check\|upgrade`） |
| `POST /api/action` | 见下表（form 或 JSON 均可） |
| `POST /api/policy` | `enabled=true\|false` |
| `POST /api/settings` | `ssid` / `passphrase` / `targetClients` / `allowWifiUplink` / `uplinkMode` / `fallbackToLan` |

`/api/action` 常用动作：`start` `stop` `ensure` `fix-peers` `rename-ssid` `board-save` `board-config` `board-autosave` `lesson-config` `lesson-clear` `hosts-refresh` `hosts-restore` `conflict-check` `conflict-choice` `conflict-preview` `conflict-snooze` `update-config` `diagnose` `repair-network` `rotate-token` `bcu` `uninstall` `exit`。

`board-save` 可带 `closeAfterSave` / `nameWithLesson`；`board-autosave` 的 `action` 取 `preview` 或 `cancel`；`lesson-config` 只接受 `enabled` / `onlyWhenClassInBoard` / `staleMinutes` / `subjects` / `skipBreakNames`；`conflict-choice` 接受 `keep-both|keep-classin|keep-seewo|keep-none`；`uninstall` 可带 `keepData=true`。
