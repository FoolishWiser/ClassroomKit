# 配置参考

配置文件：`C:\ProgramData\ClassroomKit\config.json`（首次启动自动生成；改完不用重启，守护会热加载）。桌面端「设置 / 热点 / 课表 / 板书 / 实验 / 高级 / 升级」页改的就是它。

## 分节说明

### hotspot

| 键 | 说明 |
| --- | --- |
| `enabled` | 热点策略开关。关掉后守护不再拉热点，但校园网 / 课表功能照常 |
| `ssid` / `passphrase` | 热点名与密码。默认名 = 计算机名，密码随机 8 位 |
| `band` | `auto` / `2.4` / `5`。1.0 起仍只是预留字段：系统移动热点 API 在部分网卡上不接受指定频段，当前不生效，描述见[原理与限制](原理与限制.md) §8 |
| `targetClients` | 想要的设备上限（桌面端 1–32 台） |
| `registryPeers` | 写进注册表的 `WifiMaxPeers`，默认 16 |
| `allowWifiUplink` | 是否允许用 Wi-Fi 当上行（默认不许，避免和热点抢网卡） |
| `guardIntervalSec` | 守护巡检间隔，默认 15 秒，最小 3 秒 |
| `autoStartOnLaunch` | 守护起来就顺带开热点 |
| `selfHealEnabled` | 网络异常自动修复（0.8.3 起默认开）：连续启动失败 2 次、有设备连着但上行 2 分钟没外网、最近 2 小时有设备连过却疑似假启动时，复位无线网卡并重开热点；两次至少隔 15 分钟，每天最多 3 次，零客户端且 2 小时无设备时不动 |
| `restartAdapterOnIdleNoRx` | 「假启动」自动复位网卡（默认关，空教室整夜无人连接同样零收包） |

### uplink

`mode` 为 `auto` 或网卡名 / 驱动描述片段；`fallbackToLan` 表示谁都没外网时退回局域网兜底（有网关优先，其次只有 IP 的）。

### boardSave

`enabled` 是总开关；`closeAfterSave` 保存后是否关 ClassInX；`launchIfNeeded` / `launchTimeoutSec` 控制没开 ClassInX 时要不要自动拉起；`nameWithLesson` 是否按课表改名；`nameTemplate` 支持 `{科目}` `{日期}` `{时间}` `{节次}` `{周几}`，默认 `{科目}_{节次}_{日期}_{时间}`。

1.1.0 的板书开关：`includeLessonInName` 控制 `{节次}` 是否渲染成「第3节」，关掉时该占位符渲染为空，不会自动追加；`subjectFolders` 把文件移进以科目命名的子文件夹（空科目进「未分类」）；`clearAfterSave` 保存后清屏（关掉 ClassInX 时视为已清屏）；`clearKey` 是清屏时在 Ctrl+A 之后按的键，只接受 `delete`（默认）或 `backspace`；`reusePrompt` 下一节同科目已经在上课时弹续用提示。

### lesson（课后保存）

| 键 | 说明 |
| --- | --- |
| `enabled` | 课后自动保存总开关；关掉后既不提示也不保存 |
| `onlyWhenClassInBoard` | 只在 ClassInX 运行时尝试保存（没开就没有板书可存） |
| `subjects` | 生效科目，留空 = 全部；只影响自动保存，不影响板书命名 |
| `skipBreakNames` | 这些课间名不参与自动保存（如「跑操」「高一礼让」） |
| `staleMinutes` | 课表超过这么久没更新就不动作，默认 120 |

0.9 及更早的 `remindMinutesBefore` / `dialogSeconds` / `timeoutAction` / `snoozeMinutes` 在 1.0 已删除：旧的弹窗提醒被「课间第 5 分钟起、15 秒无操作自动保存」取代，旧配置里多出来的字段读取时忽略，保存配置后自然消失。

### weici（实验 · 维词自动领读）

| 键 | 说明 |
| --- | --- |
| `appPath` | `weici-teaching.exe` 路径；留空按默认安装位置找 |
| `debugPort` | Chromium 调试端口，默认 `9222`；程序用它在已登录窗口里执行领读脚本 |
| `firstWord` / `lastWord` | 要处理的词表首词与尾词；尾词留空表示只到首词所在单元末尾 |
| `pron` | `英美混音` / `美音` / `英音` |
| `loop` | `1次` / `2次` / `3次` |
| `dryRun` | 只匹配、不真正点开始；建议先试运行一次 |

只驱动已经登录的维词窗口，不读取也不保存账号密码。

### conflict / habits

`conflict.enabled` 是冲突提示总开关；`cooldownMinutes` 同一情境冷却；`extraFullscreenProcesses` 追加自己的放映程序（进程名）；`ignoreProcesses` 忽略名单（进程名或标题命中就不参与判定）。

`habits.enabled` 打开按科目记住老师习惯；`rules` 每条形如 `{"subject":"语文","app":"wps","understand":false}`：

- `app`：`classin` / `seewo` / `wps`（也接受 classinx、希沃白板、WPS Office 等写法）；
- `understand=true`：冲突时弹窗交给老师；
- `understand=false`：老师打开习惯软件时，静默关掉另一款；
- 习惯模式开着但某科目没有规则（或 `app` 为空）：不做任何处理，既不弹窗也不关软件；
- 老师先开习惯软件、再手动开另一款：不关也不弹（只在「打开习惯软件」这个方向让路）。

### update

`checkOnBoot` 开机 90 秒后查一次；`checkIntervalHours` 定时检查（0 = 只手动）；`autoInstall` 自动安装，需同时满足时间窗、没有设备连着热点、护航任务在；`installWindow` 形如 `23:00-06:00`（可跨午夜，留空 = 全天）。

### hosts / bcu / tray / ui

`hosts.refreshHours` 是 hosts 自动刷新间隔，`sources` 是公开 hosts 源；`bcu.path` 指定 BCUninstaller 便携版位置（留空自动找）；`update.updatePlugin` 表示升级时顺带更新 ClassIsland 插件。

`tray` 控制托盘菜单：`enabled` 托盘常驻；`saveKeepOpen` 显示「保存，保留 ClassInX」；`saveWithoutRename` 显示「保存（不按课表改名）」；`showPreviewReminder` 显示「预览自动保存倒计时」。

`ui` 记窗口行为、主题、最后停留页与教程进度：`closeToTray` / `startMinimized` 控制关窗与启动形态；`windowWidth` / `windowHeight` / `windowLeft` / `windowTop` / `maximized` 是上次窗口几何（越界会回到默认）；`lastPage` 是上次停留页；`theme` 取 `light` / `dark` / `system`；`onboardingDone` 表示已完成/跳过，`onboardingStep` 是停在四步里的第几步（0–3；读取时容忍到 20，避免脏配置越界），`onboardingPaused` 表示中途收起。完成教程后左侧「教程引导」入口会消失，「关于」页仍可重新打开。
