# 配置参考

配置文件：`C:\ProgramData\ClassroomKit\config.json`（首次启动自动生成；改完不用重启，守护会热加载）。桌面端「设置 / 热点 / 课表与板书 / 高级 / 升级」页改的就是它。

## 完整示例

```json
{
  "schemaVersion": 7,
  "port": 36037,
  "token": "32 位十六进制，首次启动自动生成",
  "hotspot": {
    "enabled": true,
    "ssid": "这台电脑的名字",
    "passphrase": "随机 8 位",
    "band": "auto",
    "targetClients": 10,
    "registryPeers": 16,
    "allowWifiUplink": false,
    "guardIntervalSec": 15,
    "autoStartOnLaunch": true,
    "selfHealEnabled": true,
    "restartAdapterOnIdleNoRx": false
  },
  "uplink": { "mode": "auto", "fallbackToLan": true },
  "boardSave": {
    "enabled": true,
    "closeAfterSave": true,
    "launchIfNeeded": true,
    "launchTimeoutSec": 60,
    "classInPath": null,
    "nameWithLesson": true,
    "nameTemplate": "{科目}_{日期}_{时间}"
  },
  "lesson": {
    "enabled": true,
    "onlyWhenClassInBoard": true,
    "subjects": [],
    "skipBreakNames": [],
    "staleMinutes": 120
  },
  "conflict": {
    "enabled": true,
    "cooldownMinutes": 40,
    "extraFullscreenProcesses": [],
    "ignoreProcesses": []
  },
  "habits": {
    "enabled": false,
    "rules": [
      { "subject": "语文", "app": "wps", "understand": false },
      { "subject": "数学", "app": "classin", "understand": true }
    ]
  },
  "update": {
    "enabled": true,
    "repo": "FoolishWiser/ClassroomKit",
    "includePrerelease": false,
    "mirrors": ["https://ghproxy.net/"],
    "checkOnBoot": true,
    "checkIntervalHours": 6,
    "autoInstall": false,
    "installWindow": "",
    "installWithClients": false
  },
  "hosts": { "enabled": true, "refreshHours": 24, "sources": ["https://raw.hellogithub.com/hosts"] },
  "bcu": { "enabled": true, "path": "" },
  "tray": { "enabled": true },
  "ui": {
    "closeToTray": true,
    "startMinimized": false,
    "theme": "system",
    "onboardingDone": false,
    "onboardingStep": 0,
    "onboardingPaused": false
  }

```

越界值会被自动纠正（端口 1024–65535、巡检 ≥3 秒、目标 ≥1 台、教程步骤 0–20、升级窗口格式），坏 JSON 会回退默认并重写。全新安装时 `ssid` 默认是计算机名、`passphrase` 是随机 8 位；从 0.2/0.3 升上来的老配置，热点名与密码原样保留，只补新字段（`schemaVersion` 用来标记迁移到第几版）。

## 分节说明

### hotspot

| 键 | 说明 |
| --- | --- |
| `enabled` | 热点策略开关。关掉后守护不再拉热点，但校园网 / 课表功能照常 |
| `ssid` / `passphrase` | 热点名与密码。默认名 = 计算机名，密码随机 8 位 |
| `band` | `auto` / `2.4` / `5`。1.0 起仍只是预留字段：系统移动热点 API 在部分网卡上不接受指定频段，当前不生效，描述见[原理与限制](原理与限制.md) §8 |
| `targetClients` | 想要的设备上限（桌面端 1–32 台） |
| `registryPeers` | 写进注册表的 `WifiMaxPeers`，默认 16 |
| `allowWifiUplink` | 是否允许用 Wi-Fi 当上行（默认不许，避免和热点抢网卡） |
| `guardIntervalSec` | 守护巡检间隔，默认 15 秒，最小 3 秒 |
| `autoStartOnLaunch` | 守护起来就顺带开热点 |
| `selfHealEnabled` | 网络异常自动修复（0.8.3 起默认开）：连续启动失败 2 次、有设备连着但上行 2 分钟没外网、最近 2 小时有设备连过却疑似假启动时，复位无线网卡并重开热点；两次至少隔 15 分钟，每天最多 3 次，零客户端且 2 小时无设备时不动 |
| `restartAdapterOnIdleNoRx` | 「假启动」自动复位网卡（默认关，空教室整夜无人连接同样零收包） |

### uplink

`mode` 为 `auto` 或网卡名 / 驱动描述片段；`fallbackToLan` 表示谁都没外网时退回局域网兜底（有网关优先，其次只有 IP 的）。

### boardSave

`enabled` 是总开关；`closeAfterSave` 保存后是否关 ClassInX；`launchIfNeeded` / `launchTimeoutSec` 控制没开 ClassInX 时要不要自动拉起；`nameWithLesson` 是否按课表改名；`nameTemplate` 支持 `{科目}` `{日期}` `{时间}` `{节次}` `{周几}`。

### lesson（课后保存）

| 键 | 说明 |
| --- | --- |
| `enabled` | 课后自动保存总开关；关掉后既不提示也不保存 |
| `onlyWhenClassInBoard` | 只在 ClassInX 运行时尝试保存（没开就没有板书可存） |
| `subjects` | 生效科目，留空 = 全部；只影响自动保存，不影响板书命名 |
| `skipBreakNames` | 这些课间名不参与自动保存（如「跑操」「高一礼让」） |
| `staleMinutes` | 课表超过这么久没更新就不动作，默认 120 |

0.9 及更早的 `remindMinutesBefore` / `dialogSeconds` / `timeoutAction` / `snoozeMinutes` 在 1.0 已删除：旧的弹窗提醒被「课间第 5 分钟起、15 秒无操作自动保存」取代，旧配置里多出来的字段读取时忽略，保存配置后自然消失。

### conflict / habits

`conflict.enabled` 是冲突提示总开关；`cooldownMinutes` 同一情境冷却；`extraFullscreenProcesses` 追加自己的放映程序（进程名）；`ignoreProcesses` 忽略名单（进程名或标题命中就不参与判定）。

`habits.enabled` 打开按科目记住老师习惯；`rules` 每条形如 `{"subject":"语文","app":"wps","understand":false}`：

- `app`：`classin` / `seewo` / `wps`（也接受 classinx、希沃白板、WPS Office 等写法）；
- `understand=true`：冲突时弹窗交给老师；
- `understand=false`：老师打开习惯软件时，静默关掉另一款；
- 习惯模式开着但某科目没有规则（或 `app` 为空）：不做任何处理，既不弹窗也不关软件；
- 老师先开习惯软件、再手动开另一款：不关也不弹（只在「打开习惯软件」这个方向让路）。

### update

`checkOnBoot` 开机 90 秒后查一次；`checkIntervalHours` 定时检查（0 = 只手动）；`autoInstall` 自动安装，需同时满足时间窗、没有设备连着热点、护航任务在；`installWindow` 形如 `23:00-06:00`（可跨午夜，留空 = 全天）。

### hosts / bcu / tray / ui

`hosts.refreshHours` 是 hosts 自动刷新间隔，`sources` 是公开 hosts 源；`bcu.path` 指定 BCUninstaller 便携版位置（留空自动找）；`tray.enabled` 托盘常驻；`ui` 记窗口行为、主题、最后停留页与教程进度：`onboardingDone` 表示已完成/跳过，`onboardingStep` 是停在四步里的第几步（0–3），`onboardingPaused` 表示中途收起。完成教程后左侧「教程引导」入口会消失，「关于」页仍可重新打开。
