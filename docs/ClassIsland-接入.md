# 和 ClassIsland 配合

两种接法，按你的 ClassIsland 版本选：

| ClassIsland | 推荐做法 |
| --- | --- |
| **2.1.x（推荐）** | 装 ClassroomKit 插件（`.cipx`）：把课表推给守护（课前提醒、板书按科目改名），设置页看状态，主界面组件显示「热点 8/16 台」，自动化里上下课直接开/关 |
| 1.6 / 1.7，或不想装插件 | 零代码「自动化」：触发器 + 「运行」行动调 `ClassroomKit.Agent.exe --ensure` |

两种接法都不改变同一件事：**热点逻辑永远在独立的 ClassroomKit 守护进程里**。ClassIsland 崩了、升级了、没启动，教室里的网都不会断。

## 一、装插件（ClassIsland 2.1.x）

### 安装

1. 从 [Releases](https://github.com/FoolishWiser/ClassroomKit/releases) 下载 `ClassroomKit-<版本>.cipx`。
2. ClassIsland →「设置」→「插件」→「从本地安装」→ 选这个 `.cipx`。
3. 重启 ClassIsland（插件程序集在启动时加载）。
4. 「设置」里会多出「ClassroomKit 助手」一页。

插件要求 ClassIsland **2.1.x**（SDK 2.1.0.1，清单 `apiVersion: 2.0.0.0`）。ClassIsland 2.0 之前、1.7 之前的版本装不上，请用下面的零代码接法。

### 插件里有什么

- **设置页「ClassroomKit 助手」**：热点状态、名称、密码、已连设备数、上联网卡、守护版本；按钮「启动热点 / 关闭热点 / 修复连接上限 / 打开控制面板」；「换一个热点名称」可以一键改成电脑名；连接设置里能改地址和令牌（**令牌留空时自动读 ClassroomKit 自己的配置**）。
- **主界面组件「ClassroomKit 助手」**：一行字显示 `热点 ON · CLASSROOM-302 · 3/10`。在 ClassIsland 主界面编辑模式里添加。
- **自动化行动**：「开启教室热点」（守护没跑会先拉起来）、「关闭教室热点」、「保存板书」。配法和普通行动一样：触发器选「上课时 / 放学时 / 应用启动时」，行动选这两个。
- **课表桥**：插件后台每秒最多推一次课表快照给守护（当前科目、下一节是谁、还有多久、上一节是谁），面板「课表」卡片与课前提醒都靠它。

### 课表联动：课前提醒与板书命名

插件装上后，只要 ClassIsland 里**启用了课表**，下面两件事自动生效：

1. **课前提醒**：离下一节上课还有 5 分钟（守护配置 `lesson.remindMinutesBefore`，1–30 可调）时，守护弹一次提醒窗。默认 30 秒不操作会自动「保存板书，但不关 ClassInX」；鼠标停在窗口上倒计时暂停；键盘 <kbd>1</kbd> 保存、<kbd>2</kbd> 保存并关闭、<kbd>3</kbd> 稍后提醒、<kbd>Esc</kbd> 稍后提醒。
2. **板书命名**：保存板书时用**上一节课的科目**命名，例如 `数学_2026-11-14_10-05.png`。正在上课用当前科目，课间用刚结束的那一节；课表数据超过 2 小时没更新就退回 `黑板_日期_时间`，不瞎猜。模板在面板「课表」卡片或 `boardSave.nameTemplate` 里改。

守护侧的行为（不弹、按原因跳过）可以在面板「课表」卡片看到「当前不弹：……」，常见原因：正在上课、已放学、没有下一节课、还没到提前量、这节课已经提醒过。命令行 `--lesson-status` 看完整 JSON。

几点边界：

- 课表只用于**提醒与命名**，不影响热点开关；课表读不到时热点照常工作。
- **只在 ClassInX 正在运行时提醒**（`lesson.onlyWhenClassInBoard=true`），避免每节课都弹一个「没有板书可存」。
- ClassIsland 1.6/1.7 没有这套插件 API，装不了也拿不到课表：热点与手动保存板书仍可用，只是没有课前提醒、文件名也不会按科目改。

### 排错

| 现象 | 原因 / 处理 |
| --- | --- |
| 设置页显示「ClassroomKit 没在运行」 | 守护没启动。点「启动热点」会自动拉起；还不行就看 `C:\ProgramData\ClassroomKit\logs` |
| 提示 HTTP 401 | 先看设置页顶部的「令牌来源」：显示「空」说明没读到守护配置 —— 从面板地址里的 `?t=` 复制一次填进去；显示「已读取守护配置」还 401，则检查守护是否换了令牌（面板「更换令牌」后要重填） |
| 插件「概览」打不开 / 说缺少 README | 0.4.0 的 `.cipx` 漏了 `README.md` 与 `icon.png`，升到 0.4.1 重新安装即可 |
| 行动执行后热点没变 | 打开控制面板看日志；守护在「等待上行」时不会开热点（网线没插/无外网） |
| 装完插件在列表里看不到 | 检查 ClassIsland 版本；`.cipx` 要选对文件（不是 zip） |
| 面板「课表」一直显示未接入 | ClassIsland 没开、课表没启用，或插件没加载（重启 ClassIsland）；设置页里应能看到课表联动状态 |
| 课前不弹提醒 | 面板「课表」卡片会写「当前不弹：…」；多半是 ClassInX 没在跑、正在上课或没有下一节课 |

## 二、零代码接法（ClassIsland 1.6 / 1.7）

ClassIsland 1.6/1.7 正式版自带「自动化」：触发器 + 规则集 + 行动，**不需要写插件**。

> 2.0 预览版没有自动化面板；2.1 请用上面的插件。

### 配方 A：ClassIsland 一启动就确保热点（推荐）

1. 打开 ClassIsland →「自动化」→ 新建规则集，命名「确保热点」。
2. 触发器：**当应用启动时**。
3. 行动：**运行**，程序填：

   ```text
   C:\Program Files\ClassroomKit\ClassroomKit.Agent.exe
   ```

   参数填：

   ```text
   --ensure
   ```

4. 如果「运行」行动里有「隐藏窗口 / 不显示窗口」选项，勾上（否则可能闪一下黑框）。
5. 保存并启用。

守护已经在跑时它只发一个「确认开热点」的请求就退出（毫秒级）；守护没在跑时它会把守护拉起来。

### 配方 B：每节课开始时再确认一次

1. 同一个规则集里再加一个触发器：**上课时**（可选叠加「cron」，比如每 30 分钟一次）。
2. 行动同上（`--ensure`）。

这层是兜底：学生把热点关掉、厂商工具清理了后台进程，上课铃一响就恢复。

### 配方 C：放学后关掉（可选）

1. 新建规则集「放学关热点」。
2. 触发器：**放学时**。
3. 行动：运行 `C:\Program Files\ClassroomKit\ClassroomKit.Agent.exe`，参数 `--off`。

第二天登录时，开机自启 + 配方 A 会重新开起来（`--off` 只关热点，不影响守护进程）。

### 验证

1. 面板显示「热点已开」。
2. 在 ClassIsland 里手动触发一次规则集。
3. 面板日志里应出现一条「策略：开启热点」或「已在运行」。
4. 想更彻底：任务管理器结束 `ClassroomKit.Agent.exe` → 触发规则集 → 托盘图标和面板都应回来，热点恢复。

## 常见坑

- **路径有空格**：`C:\Program Files` 里有空格，零代码「运行」行动可能需要自己加引号。
- **别用 `--on` 代替 `--ensure`**：`--on` 只改策略、不会拉起守护；`--ensure` 才是「确保在跑且开着」。
- **别把 exe 放到用户目录**：一体机多人共用时，别的账号跑不到。
- **ClassIsland 以管理员运行**：没影响，守护是用户级的，管理员进程调它一样能用（走同一个 TCP 端口，天然串行）。
