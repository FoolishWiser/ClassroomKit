# 和 ClassIsland 配合（零代码）

ClassIsland（1.6 / 1.7 正式版）自带「自动化」：触发器 + 规则集 + 行动，**不需要写插件**。

> 2.0 预览版暂时没有自动化面板，配规则请用 1.6/1.7 正式版。

## 先理解分工

- **ClassroomKit 负责热点本身**：登录后 8 秒自己起，崩了/被关了自己恢复。ClassIsland 没开、老师没登录、课表软件正在升级，热点都照常工作。
- **ClassIsland 只做「保险」**：万一热点被别的软件关了、或者这台机器装完还没重启，让课表软件在启动时/上课时喊一声。

两边是「内核 + 薄壳」的关系，任何一边单独存在都不影响上网。

## 配方 A：ClassIsland 一启动就确保热点（推荐）

1. 打开 ClassIsland →「自动化」→ 新建规则集，命名「确保热点」。
2. 触发器：**当应用启动时**。
3. 行动：**运行**，程序填：
   ```text
   C:\Program Files\ClassroomKit\ClassroomKit.Agent.exe
   ```
   参数填：
   ```text
   --ensure
   ```
4. 如果「运行」行动里有「隐藏窗口 / 不显示窗口」选项，勾上（否则可能闪一下黑框）。
5. 保存并启用。

效果：ClassIsland 每次启动都会调一次 `--ensure`。守护已经在跑时它只发一个「确认开热点」的请求就退出（毫秒级，不占资源）；守护没在跑时它会把守护拉起来。

## 配方 B：每节课开始时再确认一次

1. 同一个规则集里再加一个触发器：**上课时**（可选叠加「cron」，比如每 30 分钟一次）。
2. 行动同上（`--ensure`）。

这层是兜底：有的教室会遇到学生把热点关掉、或者厂商工具清理了后台进程，上课铃一响就恢复。

## 配方 C：放学后关掉（可选）

如果希望放学后热点消失（省电、减少被蹭网）：

1. 新建规则集「放学关热点」。
2. 触发器：**放学时**。
3. 行动：运行 `C:\Program Files\ClassroomKit\ClassroomKit.Agent.exe`，参数 `--off`。

第二天登录时，开机自启 + 配方 A 会重新开起来（`--off` 只关热点，不影响守护进程）。

## 验证

1. 面板显示「热点已开」。
2. 在 ClassIsland 里手动触发一次规则集（或用「运行」行动立即执行）。
3. 面板日志里应出现一条「策略：开启热点」或「已在运行」。
4. 想更彻底：任务管理器结束 `ClassroomKit.Agent.exe` → 触发规则集 → 托盘图标和面板都应回来，热点恢复。

## 什么时候才需要写插件（v1.1，可选）

只有当你想让 ClassIsland 的界面上**直接显示热点状态**（比如主界面显示「热点 8/16 台」、或课表界面加一个开关）时才需要插件。插件做法是薄壳：读 `GET http://127.0.0.1:36037/api/state?t=令牌` 渲染，按钮调 `POST /api/action`。热点逻辑永远留在守护进程里，插件崩了不影响上网。

## 常见坑

- **路径有空格**：C:\Program Files 里有空格，某些「运行」行动需要自己加引号，先按上面的完整路径试，不行再套一对英文双引号。
- **别用 `--on` 代替 `--ensure`**：`--on` 只改策略、不会拉起守护；`--ensure` 才是「确保在跑且开着」。
- **别把 exe 放到用户目录**：一体机多人共用时，别的账号跑不到。
- **ClassIsland 以管理员运行**：没影响，热点守护是用户级的，管理员进程调它一样能用（只是会走同一个 TCP 端口，天然串行）。
