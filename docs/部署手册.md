# 部署手册

适用：Windows 10 19041 及以上（一体机 OPS 电脑常见 19045），管理员权限，上行网络走**网线**。

## 0. 前置检查（只在一台样机上做一次）

把 `dist` 目录里的东西拷到样机，管理员 PowerShell：

```powershell
.\ClassroomKit.Agent.exe --probe
```

关心的字段：

| 字段 | 期望 | 不对怎么办 |
| --- | --- | --- |
| `wlanAdapter` | 有无线网卡型号 | 没无线网卡就别装了 |
| `tetheringCapability` | `Enabled` | 是 `DisabledBy*` 说明被组策略/硬件/运营商禁用，换机或改策略 |
| `maxClientCount` | 8（默认） | 写注册表后会变 16，见验收项 3 |
| `uplink.isWifi` | false | 上行是 Wi-Fi 时本工具默认拒绝开热点（会把仅有的无线占掉） |

## 1. 打包（在开发机做，一体机不用装 SDK）

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build.ps1
```

产物在 `dist\`：单文件 `ClassroomKit.Agent.exe`（自包含约 70 MB）+ `web\` + `scripts`。

手工等价命令：

```powershell
dotnet publish src/ClassroomKit.Agent/ClassroomKit.Agent.csproj -c Release -r win-x64 ^
  --self-contained true -p:PublishSingleFile=true ^
  -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true -o dist
```

> publish 不会带脚本，记得 `Copy-Item scripts\*.ps1 dist\`。

## 2. 用 MSI 安装（推荐）

`ClassroomKit-0.2.10-x64.msi`（约 62 MB，自带运行时，一体机不用装 .NET）：

```text
双击安装；或静默：msiexec /i ClassroomKit-0.2.10-x64.msi /qn
卸载：msiexec /x ClassroomKit-0.2.10-x64.msi /qn      （也可以走「应用和功能」）
```

MSI 只负责「放文件 + 在正确时机调用本体」，真正要做的事由 `ClassroomKit.Agent.exe --msi-setup` 完成（以 SYSTEM 身份、不改执行策略依赖 PowerShell）：

| 阶段 | 动作 |
| --- | --- |
| 安装后 | 建 `C:\ProgramData\ClassroomKit` 并把 Users 组授权为可修改 → 生成配置（已存在则保留）→ 写 `WifiMaxPeers=16` → 重启 `icssvc` → 注册登录自启任务 → 立刻拉起守护 |
| 卸载前 | 停守护 → 删计划任务 → 删除 `WifiMaxPeers` 并重启 `icssvc`（恢复系统默认上限）→ 结束并删除 `BCU` 目录 → **保留** `C:\ProgramData\ClassroomKit` |

几点要注意：

- **托盘图标可见**：MSI 的自定义动作跑在 Session 0，直接 `schtasks /Run` 会把进程拉进 Session 0（没托盘）。所以安装流程改用「交互令牌的临时任务」把进程送进当前 console 用户会话（实测 `SessionId=1`）；当时没人登录就跳过，等下次登录由常驻任务启动。
- **升级**：换版本号重建 `msiexec /i` 直接覆盖（`MajorUpgrade`）。`ProductCode` 由版本号算出——同版本重装是「同一产品」替换，不会在「应用和功能」里留两行。
- **静默安装日志**：加 `/l*v %TEMP%\ck.log` 之类看细节；本体自己的日志在 `C:\ProgramData\ClassroomKit\logs\msi-setup.log`。
- **BCU 不进包**（249 MB）：装完想用「强力卸载」按钮，跑一次 `get-bcu.ps1`，或把便携版解到 `C:\Program Files\ClassroomKit\BCU\`。
- **自己构建**：`powershell -ExecutionPolicy Bypass -File scripts\build-msi.ps1 [-Version 0.2.10]`，需要先 `dotnet tool install --global wix --version 5.0.2`（v7 要付费许可，别用）。脚本会扫描 `dist\` 自动生成文件清单 `installer\files.wxs`，所以改完代码记得先 publish 到 `dist\` 再打包。

## 3. 绿色目录安装（install.ps1）

```powershell
cd D:\ClassroomKit
powershell -ExecutionPolicy Bypass -File install.ps1 ^
  -Ssid "CLASSROOM-302" -Passphrase "80258025" -TargetClients 10 -WithBCU
```

参数：

| 参数 | 说明 |
| --- | --- |
| `-InstallDir` | 默认 `C:\Program Files\ClassroomKit` |
| `-Ssid` / `-Passphrase` | 默认 `CLASSROOM-302` / `80258025`（密码至少 8 位） |
| `-TargetClients` | 设计容量，面板显示「x/目标」，同时决定注册表放宽值（`max(目标+6,16)`） |
| `-WithBCU` | 顺带部署强力卸载工具；配合 `-BcuSource <目录>` 从便携版复制 |
| — | 没带 BCU 不影响主功能：之后在目标机上跑一次 `get-bcu.ps1` 就能补上（约 100 MB，自带运行时） |
| `-SkipRegistry` | 不动 `WifiMaxPeers`（只在已知会撞组策略时用） |
| `-NoStart` | 装完不立即启动（等重启验证自启） |

重复执行是幂等的；`C:\ProgramData\ClassroomKit\config.json` 已存在时会保留（SSID/密码不会被打回默认）。

它做的事：停旧进程 → 复制程序 → 建数据目录并 `icacls` 授权 Users 可写（否则普通权限的守护写不了日志和配置）→ 写配置 → `WifiMaxPeers` → 重启 `icssvc` → 注册计划任务 `ClassroomKit-Agent`（登录触发、延迟 8 秒、Users 组、最低权限、失败每分钟重试 3 次）→ 启动守护 → 打印面板地址与热点密码。

## 4. 验收清单

1. 面板 `http://127.0.0.1:36037/?t=令牌` 能开，右上角「热点已开」为绿色。
2. 手机连面板上显示的热点名（全新安装 = 这台电脑的计算机名，例如 `DESKTOP-PRE862I`），能拿到 `192.168.137.x` 并能上网。若面板顶上提示「热点名还是旧的默认值」，点「改用电脑名」。
3. 面板「系统上限」显示 **16 台**（不是 8）。若还是 8：`ClassroomKit.Agent.exe --fix-peers`（会弹一次 UAC），然后关/开一次热点。
4. 「无设备自动关」显示 **已关闭**。若没有，看日志里有没有「无法关闭"无设备 5 分钟自动关热点"」。
5. 拔掉网线：面板变「等待上行」，插回去 15 秒内自动恢复成「运行中」。多块网卡时确认面板「上行」一栏是**有外网**的那块（`--uplinks` 可查选择理由）。
6. 手动关掉热点（面板「关闭热点」→ 再「开启热点」）：都能在 5 秒内生效。
7. 重启电脑：**不登录也能看到热点**？——不能，热点要用户会话。登录后约 8–10 秒热点起来，托盘出现图标。
8. **托盘与主界面**：双击 \`ClassroomKit.Agent.exe\` 或开始菜单「ClassroomKit 助手」→ 桌面主界面（左侧六页）；点托盘图标（左键或右键）弹同一份菜单，首项「打开主界面」；关窗口后应收进托盘，守护继续跑。
9. 十台设备同时连（真机验收项，见「已知限制」）。
10. **板书保存**：ClassInX 里打开任意板书 → 托盘右键「保存板书」→「保存并关闭 ClassInX」→ 2 秒内弹出气泡提示「3 个文件」，`文档\ClassIn X Files\` 里出现同名的 `.edb/.png/.pdf`，ClassInX 已退出。再开一次同样操作，验证「文件已存在，是否替换」也被自动处理。
    再把 ClassInX 完全退出（托盘退出 + 任务管理器确认没有 `ClassIn X.exe`）→ 再点一次菜单：应当先自动启动 ClassInX，等板书窗口出现后继续保存；若它停在「启动台 / 主界面」而没有课堂板书，气泡会说「ClassInX 弹了提示…请先在板书上写点内容」，这是对的（没有内容就存不出文件）。
11. **冲突提示**：同时开着希沃白板和 ClassInX（各自悬浮窗都在）→ 打开 WPS 放映，或把 ClassInX/希沃任意一个切到全屏 → 2 秒内弹出提示窗（圆角卡片、四个选项带应用图标与数字徽标）。逐项核对：
    - 鼠标停在窗口上 → 倒计时与进度条停住，移开继续；
    - 按 <kbd>1</kbd>–<kbd>4</kbd> 能直接选，<kbd>Esc</kbd>/<kbd>Enter</kbd> 等于「都保留」，<kbd>S</kbd> 能勾/取消「今天不再提醒」；
    - 60 秒不动自动选「都保留」；
    - 勾「今天不再提醒」后确认面板「板书冲突提示」显示「暂停中」，点「恢复提醒」后恢复「监听中」。
    想先看长相而不必真造场景：`ClassroomKit.Agent.exe --conflict-preview`，或面板点「预览提示窗」（`POST /api/action {"action":"conflict-preview"}`）。
12. **课表联动（前置：装好 .cipx 插件、ClassIsland 里启用了课表）**：
    - ClassIsland 开着课表并正常走时，面板最上面的「课表」卡片应显示「课间 / 准备上课」之类状态，并写出下一节科目与还有多久；`--lesson-status` 能看到 `available=true`。
    - 关掉 ClassIsland 或停掉插件 → 卡片变成「未运行 /还没收到课表」，热点不受影响。
    - 点「预览课前提醒」：弹出提醒窗，核对圆角卡片、四个按钮、倒计时；鼠标悬停暂停；<kbd>1</kbd> 保存、<kbd>2</kbd> 保存并关闭、<kbd>3</kbd> 稍后、<kbd>Esc</kbd> 稍后。默认 30 秒后自动「保存，不关 ClassInX」。
    - 等真实课前 5 分钟（或把 `lesson.remindMinutesBefore` 临时改大、或 `--lesson-reminder-test --show`）确认只弹一次；同一节课再等不会重复弹。
    - 保存后看 `文档\ClassIn X Files\`：文件名应为 `科目_日期_时间`（如 `数学_2026-11-14_10-05.png`）；关掉课表再存一次，应退回 `黑板_日期_时间`。
    - 面板「课表」卡片里改提前量/弹窗秒数/超时动作，保存后刷新确认生效（`config.json` 的 `lesson` 段）。
13. **一键自检**：面板「开始自检」应在一秒内出 11 项，全部「正常」或「注意」；命令行 `--diagnose` 输出同样内容。
14. **护航任务与插件概览（0.4.1 起）**：
    - `Get-ScheduledTaskInfo ClassroomKit-Service` 的 `LastRunTime` 不应还是 1999 年；面板 hosts 卡显示「护航任务在跑」，`%ProgramData%\ClassroomKit\service\heartbeat.json` 应在一刻钟内更新。
    - 若 hosts 卡出现「安装护航任务」按钮：点一次 → 允许管理员授权 → 按钮消失、状态转为已生效（不用再敲 `--install-service`）。
    - 打开 ClassIsland 插件列表 → ClassroomKit 助手 →「概览」应显示插件自述（README），不是空白报错；图标不是默认占位图。

15. **桌面端（0.5.0 起）**：
    - 双击 `C:\Program Files\ClassroomKit\ClassroomKit.Agent.exe`（或开始菜单「ClassroomKit 助手」）→ 弹出主界面，左侧六页能逐个切过去，底部状态文字正常。
    - 点窗口右上角 × → 窗口消失、托盘图标还在（默认关窗收托盘）；点托盘图标（左键或右键）→「打开主界面」能把它叫回来。
    - 换成深色主题、改一下窗口大小和位置 → 退出程序再打开：主题、尺寸、位置、最后停留的页面都还在（`config.json` 的 `ui` 段）。
    - 「课表与板书」页不接 ClassIsland 时显示占位文案，接上后显示当前/下一节与「保存后的文件名预览」；改提前量/秒数/超时动作后保存，`config.json` 的 `lesson` 段跟着变。
    - 「自检与日志」页点「开始自检」→ 11 项一秒内出结果并按正常/注意/有问题着色。
    - 「即时保存板书」点下去窗口不卡（后台跑），ClassInX 起来后气泡提示文件数。

## 5. 还原卡 / 冰点

三种情况，按机器实际能力选：

| 情况 | 做法 |
| --- | --- |
| 能排除目录 | 把 `C:\Program Files\ClassroomKit` 和 `C:\ProgramData\ClassroomKit` 加入还原排除列表，最省事 |
| 只能保 D 盘 | 安装包放 `D:\ClassroomKit-Package\`，装到 D 盘：`install.ps1 -InstallDir D:\ClassroomKit`；还原后由开机脚本跑 `scripts\rebuild.ps1 -PackageDir D:\ClassroomKit-Package` |
| 全盘冻结 | 同「只能保 D 盘」，rebuild.ps1 会重做计划任务和注册表值 |

`rebuild.ps1` 就是「打包目录里再跑一遍 install.ps1」，幂等，可放进开机计划任务。

### 多块网卡 / 学校没有外网

一体机常有 2–3 块有线网卡（校内网、监控、预留各一块），学校有时整片断外网。程序不依赖 Windows 的“默认连接”，而是自己挑：

| 情形 | 行为 |
| --- | --- |
| 一块有外网、其它没有 | 自动选有外网的那块，不管它的 metric 是不是更小 |
| 都没外网、但有网关 | 局域网兜底（`fallbackToLan`，默认开）：热点照开，学生能访问一体机，只是上不了外网 |
| 连网关都没配、只有 IP | 也允许兜底开热点（优先级最低）。这条专治“学校只给 IP”和“默认路由刚被删”的网络抖动 |
| 只剩 Wi-Fi 能上网 | 默认拒绝（拿 Wi-Fi 开热点会断自己的网），面板可显式允许 |
| 本机热点网卡 `192.168.137.x` | 永不被选，避免自己共享自己 |

想固定某块网卡：面板「上行网卡」下拉选中它（或 `config.json` 里 `uplink.mode` 写网卡名 / Id / 驱动描述片段）。指定的网卡拔线后自动回退自动选择。命令行体检：`ClassroomKit.Agent.exe --uplinks`。

### 板书保存与冲突提示

这两个功能依赖界面自动化，装机后建议各验一次（验收清单第 10、11 条）。

| 场景 | 处理 |
| --- | --- |
| 点了菜单没反应 / 提示找不到 ClassInX | ClassInX 没装、装在非常规位置，或 `boardSave.launchIfNeeded` 被关掉了。手动指定 `config.json` 的 `boardSave.classInPath` 指向 `ClassIn X.exe` |
| 已经自动启动 ClassInX 了，但还是说存不了 | 自动启动后它停在「启动台 / 主界面」，没有课堂板书——进课堂、打开板书、写上内容再点一次即可 |
| 等了很久没等到板书窗口 | 学校机器慢/ClassInX 冷启动慢：把 `boardSave.launchTimeoutSec` 调大（最大 600） |
| 保存出来的文件缺 pdf（或少了别的格式） | 勾选框判定靠像素，界面主题/缩放变了会失准：`--probe-classin` 重新探测后重试；仍不行就手动勾一次 pdf 再让程序保存 |
| 保存后 ClassInX 没关 | 托盘菜单里选的是「保存并关闭」吗？`boardSave.closeAfterSave` 可能被设成 `false` |
| 弹窗太频繁 / 根本不弹 | `config.json` 的 `conflict.cooldownMinutes`（默认 40）调节频率；想立刻验证：`POST /api/action {"action":"conflict-check","force":true}` |
| 学校的放映软件不是 WPS | 在 `conflict.extraFullscreenProcesses` 里加进程名（如 `pptxview`），只要它占满全屏就能触发 |
| 点了「保留希沃白板」但希沃没关 | 先关窗口，5 秒不退才结束进程；个别版本有保护进程（`EasiNote.BrowserSubprocess`），日志会写关闭结果 |

## 6. 升级

**推荐：面板/托盘内置的 GitHub 升级**（0.2.2 起）

1. 桌面端「升级」页（或网页面板「升级」卡片、托盘菜单「检查更新…」）→「检查更新」→「立即升级」；
2. **不需要点任何确认**：安装包交给 SYSTEM 护航任务静默安装（最多等 5 分钟，护航任务每 5 分钟醒一次）；热点会断 1–2 分钟，随后自动恢复；
3. 面板刷新，`version` 变成新版本号即完成。

想让它自己装：面板「升级」卡片里打开**自动安装**；时间窗默认留空=全天，只要「没有设备连着热点」就装，上课中间不会断网。需要避开上课就填 `23:00-06:00` 这类窗口。
没有护航任务（绿色版没跑 `--install-service`）时才会弹一次 UAC。

命令行等价：`ClassroomKit.Agent.exe --check-update`（只查）、`--update`（下载并装）。
学校网络屏蔽 GitHub 时检查会明确报错，直接手动下载 MSI 双击安装即可（效果相同）。下载安装包时按「GitHub API 资产接口 → 直连 → `config.json` 的 `update.mirrors`（默认 `https://ghproxy.net/`）」依次尝试，安装包落地后按 GitHub API 的 sha256 校验。
安装日志在 `C:\ProgramData\ClassroomKit\logs\update.log`。

**手动升级（绿色版 / 没有网络时）**

1. 新版 `dist` 覆盖旧目录；
2. 管理员跑 `install.ps1`（默认保留现有配置）；
3. 面板刷新，确认 `version` 变了。

要重置配置：删掉 `C:\ProgramData\ClassroomKit\config.json` 再装（令牌会重新生成，旧书签失效）。

MSI 装的情况：改好代码 → `build.ps1` 或 publish 到 `dist\` → `build-msi.ps1 -Version 0.2.10` → `msiexec /i ClassroomKit-0.2.10-x64.msi`，旧版由 `MajorUpgrade` 自动移除。反向降级会被拒绝（包里有 DowngradeErrorMessage），要降先卸载。

## 7. 卸载

```powershell
powershell -ExecutionPolicy Bypass -File uninstall.ps1            # 只删程序
powershell -ExecutionPolicy Bypass -File uninstall.ps1 -RemoveData -RestorePeerLimit
```

`-RestorePeerLimit` 会删掉 `WifiMaxPeers` 并重启 `icssvc`（恢复系统默认 8 台）。

MSI 装的情况：`msiexec /x ClassroomKit-0.2.10-x64.msi /qn`，或「应用和功能」里卸载。它同样会关热点、删计划任务、恢复 `WifiMaxPeers`、结束并清掉 `BCU` 目录，并**保留** `C:\ProgramData\ClassroomKit`（想彻底清就手工删这个目录）。

**不经控制面板也能卸**（老师自己能操作，不用找管理员要安装包）：

| 方式 | 说明 |
| --- | --- |
| 面板「维护」卡片 →「卸载本软件」 | 会弹一次 UAC，点「是」；可勾「同时删除配置与日志」 |
| `ClassroomKit.Agent.exe --uninstall` | 同上，管理员 PowerShell 里跑不会弹 UAC |
| `ClassroomKit.Agent.exe --uninstall --purge-data` | 连 `C:\ProgramData\ClassroomKit` 一起删 |

MSI 装的时候，卸载脚本会自己找出 ProductCode 再调 `msiexec /x`，不需要安装包本体；绿色版则自己关任务、恢复注册表、删目录。

## 8. 排障

| 现象 | 原因 / 处理 |
| --- | --- |
| 面板打不开 | 守护没起：`--status`；端口被占则改 `config.json` 的 `port` 后重启 |
| 面板 401 | 令牌不对，地址必须带 `?t=令牌`（面板会把令牌存进 sessionStorage） |
| 状态「等待上行」 | 网线没通 / 以太网没获得 IP / 上行被禁用 |
| 状态「上行是 Wi-Fi，拒绝开热点」 | 机器只有 Wi-Fi 上网；面板勾「允许 Wi-Fi 当上行」会断掉自身网络，别勾 |
| 上限还是 8 | `--fix-peers` 没跑成功（看 `C:\ProgramData\ClassroomKit\last-fix.txt`），或组策略覆盖了 `icssvc\Settings` |
| 热点开了又自己没 | 无设备自动关没关成功，看日志；个别网卡驱动会自己关，GUI 里重开一次并观察 |
| 托盘没图标 | 托盘只在「已登录的桌面会话」里出现。MSI 装完会自动把进程送进当前登录用户的会话；如果是远程/静默部署（安装程序跑在 Session 0）或当时没人登录，就会等到下次登录才启动。日志里若有「当前运行在 Session 0…」这句，就是这种情况：从开始菜单点「ClassroomKit 控制面板」重启一次即可 |
| 日志说「当前运行在 Session 0」 | 与上一条同因：热点照常工作，只是没有托盘和自启面板；重新登录或从开始菜单启动即可 |
| 强力卸载提示找不到 BCU | 跑一次 `powershell -ExecutionPolicy Bypass -File get-bcu.ps1`（自动下载解压到 `C:\Program Files\ClassroomKit\BCU\`）；也可手动放 `BCUninstaller.exe` 到那里，或在 `config.json` 写 `bcu.path` |
| 板书保存失败：勾选框状态不对 | 界面主题/DPI 变了，`--probe-classin` 重新探测；或手工改 `C:\ProgramData\ClassroomKit\ui-recipe.json` 里的坐标 |
| 板书保存失败：没找到板书窗口 | ClassInX 没开或不在板书界面；程序会自动拉起 ClassInX（`boardSave.launchIfNeeded`），拉起来后仍停在启动台就没有板书可存 |
| 板书保存失败：ClassInX 弹了提示（板书内容为空） | 板书上还没写东西，ClassInX 拒绝保存。先写点内容再点菜单 |
| 板书保存失败：无法把 ClassInX 切到前台 | 有别的全屏程序（如放映）压着；程序会先清掉 ClassInX 残留的提示框再重试，仍失败就手动点一下 ClassInX 窗口 |
| 冲突提示一直不弹 | 需要「两个悬浮窗同时存在」+「全屏」两件事都成立；`GET /api/board` 会明确写当前判到了什么、为什么不触发 |
| 日志在哪 | `C:\ProgramData\ClassroomKit\logs\agent-yyyyMMdd.log`，保留 14 天 |
