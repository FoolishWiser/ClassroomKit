## ClassroomKit 0.2.7

### 修「点「保存至本地」点偏低、面板打开后勾选框点不中」

上一版按 1.5 倍折算坐标，但 ClassInX 的图标/面板布局和配方不是严格等比：点「保存至本地」实际落在图标下方的文字上；面板实测 510×519，按比例推出来只有 510×417，折算式点击全部偏掉。

- **图标和按钮改成按像素找**：「保存至本地」认黄橙色圆图标；面板里认绿色勾选框行和绿色「保存」按钮，坐标直接来自截图，不再依赖配方尺寸
- 面板识别放宽高度容差（面板高度会随保存路径长短变化），并要求与保存对话框重叠，不会再把登录卡片当面板
- 找不到颜色特征时仍退回配方坐标，老机器不会更差
- 勾选框只在没勾时点（.pdf 默认不勾，自动补上；已勾的 .edb/.png 不会点掉）

### 升级

- 面板「升级」→ 检查更新 → 下载并升级；或直接装 `ClassroomKit-0.2.7-x64.msi`
- `C:\ProgramData\ClassroomKit\update` 里的旧安装包会在启动时自动清掉，只留最新一个待安装包
