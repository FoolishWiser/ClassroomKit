# ClassroomKit 1.1.0

1.1.0 修掉报告里影响中等及以上的问题，并把升级后的第一屏、连堂保存和清屏这三件最容易打断课堂的事重新做顺。

- **升级、安装完自动打开主界面**：首次安装和升级成功都会带 `--show` 启动并强制显示主界面，不再只留一个托盘图标等老师去点；开机自启仍保持安静，只到托盘。升级失败也会把用户会话里的实例拉回来。
- **连堂课间不保存**：删掉「连堂课间也保存」开关，同一科目的连续两节只在最后一段下课保存一次，板书不再被切成两半；续用提示只在下一节同科目已经上课时出现。
- **清屏改成键盘**：保存后把板书窗口切到前台，确认前台后 Ctrl+A 全选，再按 Delete（可在「板书」页改成 Backspace）。前后截 32×32 亮度指纹比对，没变化就换另一个键；仍没变化只记日志，不谎报成功。原「清屏按钮 + 坐标校准」整条链路删除。
- **自动保存不再无限顺延**：老师持续碰鼠标键盘时，冷却最多顺延 60 秒，到点必须保存，避免一直拖到下课还没存。
- **保存链路更保守**：不再写死「必须有 3 个新文件」，改为至少 2 个且 PDF 完整、所有文件大小连续 400ms 不变；保存中禁止重入；`ClassIn X` / `ClassInX` / `ClassIn` 三种进程名都认；复选框只认绿色填充；保存异常不再带崩托盘；文件名不再自动追加 `_第N节`；索引和续用状态坏文件会备份成 `.bad-时间戳`；续用窗 60 秒自动关闭，保存中不弹。
- **升级与安装更稳**：msiexec 超时从 10 分钟放宽到 30 分钟且不再强杀进程树；接受退出码 1641；安装后配置失败返回 1603，不再假装成功；UAC 升级不再把脚本写到普通用户可改的目录；插件覆盖失败会回滚，ClassIsland 正在运行时先不动插件；资产没有 sha256 直接拒绝安装；下载超时单独提示，不再当成用户取消；下载结束不再用 Ready 冲掉 Installing；静默安装会拒绝不会升级的旧请求。
- **卸载更干净**：卸载前先等正在进行的板书保存结束、抬掉 Ctrl/Alt；卸载时尽量关闭热点；绿色版残留的 SYSTEM 护航任务一并删除；程序目录不像 ClassroomKit 专属目录时不再 `rmdir /s /q` 整个目录。
- **热点与命令更可信**：热点名/密码先校验再提示已保存；读取在线设备失败时保留上次列表并标记「未知」，不再冒充零设备；Wi-Fi 上行时拒绝复位无线网卡；同一网卡多个连接配置按外网可用性挑；两块无线网卡时复位承载热点的那块；`--ensure` 20 秒内接口没响应就返回失败；`--rotate-token` 让运行中的守护立即换令牌；`--restart-wifi` 交给守护协商。
- **诊断包真正脱敏**：计算机名、用户名、热点名、设备名、IP、MAC、本地绝对路径都变成掩码或占位符；`--probe` 输出同样脱敏，不再泄露用户名和路径。
- **维词实验页**：首词为空直接报错；尾词留空只领第一个词；没点到页脚「开始」不再报 READY；设置没生效、端口不是维词、取消后页面继续点开始都有明确结果；扫描和运行使用启动时的配置副本；取消时先停止页面脚本。
- **不再发绿色版**：Release 只提供 MSI 与 `.cipx`；CI 增加 pull request 构建（只测不发），构建与校验都去掉了 zip。
- 配置 schema 升到 9（删除 `lesson.saveConnectedClasses`，新增 `boardSave.clearKey`）；测试 224 项全部通过。

## 历史：1.0.0

1.0 是 ClassroomKit 的第一个正式版。它不再用弹窗打断课堂，而是安静地等老师离开，再把板书存好；同时把老师每天要用的三件小事——告诉学生怎么连、看谁连着、去哪找板书——放进了主界面。

从 0.8.3 升上来不用改配置，schema 仍是 7；旧版留下的提醒窗字段会在下次保存配置时自然消失。

- **课后自动保存，不再弹窗**：课间开始 5 分钟后进入 15 秒倒计时，ClassIsland 通知区显示「还剩 N 秒自动保存板书」。这 15 秒里动一下鼠标或键盘就算打断，10 秒后再试；一直拖到上课前 2 分 30 秒就放弃当次，不抢开课窗口。连堂只存最后一段，`lesson.skipBreakNames` 里的课间不动作。
- **为什么这样改**：原来的 30 秒提醒窗会盖在课件上，老师得先关窗再上课；现在保存发生在老师离开之后，课堂里看不到任何窗口。保存成功后文件仍按「科目_日期_时间」命名，0 字节 / 半截 PDF 仍判失败。
- **投屏连接卡**：热点页一键全屏显示 SSID 与密码，大字、可复制、两分钟自动收起。学生问「密码多少」时不用再把脑袋凑到屏幕前。
- **在线设备**：热点页新增设备卡，列出名称、IP、MAC 与已连接时长；同一台设备刷新后时长继续增长，而不是永远「刚刚」。
- **板书中心**：「课表与板书」页直接显示保存目录、文件总数/总大小、磁盘剩余与最近 5 个文件，一键打开目录。
- **教程不再赖在侧边栏**：中途收起会记住步骤，下次从原处继续；完成后左侧入口消失，「关于」页仍可重开。
- **诊断包与崩溃日志**：自检页可导出脱敏 zip（自检、环境、配置摘要、在线设备、最近日志），未处理异常写到 `logs\crash-*.txt`，反馈问题不用再靠猜。
- **收尾清理**：去掉 0.8.2 遗留的网页面板文案与旧提醒窗代码；`--lesson-reminder-test --show` 只给迁移提示。新增 `GET/POST /api/board-autosave`，`GET /api/state` 带 `boardAutoSave`；旧 `board-reminder-snooze` 返回 410。
- 测试 211 项全部通过；整机验收清单更新到 1.0。

## 历史：0.8.3

0.8.3 把 0.6.6 那台希沃一体机热点故障的教训做成会自动执行的修复：网络异常时先复位无线网卡并重开热点，也能在自检页手动触发。

- **三类异常自动修复**：热点连续启动失败 2 次、有设备连着但上行持续 2 分钟没有外网、最近 2 小时有设备连过却零客户端且 AP 收包不涨（疑似假启动）时，自动复位无线网卡并重开热点。
- **安全阀**：两次自动修复至少隔 15 分钟、每天最多 3 次；零客户端且最近 2 小时没设备连过时不动网卡，避免空教室整夜反复打断希沃传屏；上行是有线且无外网时只提示，不复位无线网卡。
- **自检页能看能手动修**：新增「网络自我修复」卡，显示开关状态、累计次数与最近一次原因；点「检查并修复」会先判断（策略关 / 无上行 / 有线无外网 / 一切正常）再决定是否复位。
- **可配置**：`hotspot.selfHealEnabled` 默认开；`hotspot.restartAdapterOnIdleNoRx` 仍是更激进的零客户端复位开关，默认关。
- **接口与自检**：`GET /api/state` 增加 `selfHeal` 字段，`POST /api/action action=repair-network` 可手动触发；`--diagnose` 报告新增 `selfheal` 项。
- 测试 200 项全部通过。

## 历史：0.7.0

## 历史：0.6.4

0.6.4 是一次「防假死」加固：把几处会卡住线程、卡住整机输入的地方改掉，功能与界面不变。

- **每秒一次的 schtasks 查询停掉了**：面板以前每秒钟都去查一次「护航任务」状态，背后是启动 `schtasks.exe` 并同步读到它退出；一旦 schtasks 变慢（机器忙、杀软扫描），调用线程就永久挂着，面板停止刷新、线程池被抽干，整机看起来像死机。现在结果缓存 30 秒，并且先等进程退出再读输出、5 秒超时直接杀掉。
- **后台不再弹 UAC**：网页 / HTTP 接口与巡检路径调用「修复客户端上限」时不再尝试提权弹框；没有可交互桌面就返回一句说明，到电脑前手动点一次即可。所有提权等待都带 120 秒超时，超时杀掉进程。
- **不再每分钟全盘扫 ClassIsland**：机器上没装 ClassIsland 时，以前每分钟都会重新扫一遍用户目录与 Program Files（深度 4、每根 4000 个目录），机械盘和 OneDrive 上足以把磁盘队列打满。现在空结果也走缓存，连续 3 次为空退避到 30 分钟，扫描深度降到 3、每根 1500 个目录、单次 8 秒预算。
- **一次异常不会带走键盘鼠标**：切前台、拖拽、Ctrl+S 这些注入动作全部加了 try/finally，异常或中断也会把 ALT 与鼠标键抬起来；守护启动时还会先做一次「释放所有注入按键」。以前中断后整个桌面像死机，重启本程序也不恢复。
- **冲突提示窗不再冻住界面**：悬停暂停最多延长 15 秒；关进程的操作挪到后台线程，关窗后界面不会再「未响应」五到十几秒；托盘询问框 5 秒没反应就按「不升级」处理。
- **日志改成批量落盘**：以前每条日志同步写盘并持全局锁，磁盘一慢所有调用方一起等。现在先进内存队列，由后台线程每 500 毫秒或满 200 条刷一批，退出时兜底写完。
- **HTTP 面板加了连接上限**：最多同时处理 16 个连接，accept 异常后先退避 200 毫秒，不再空转吃满一个核。
- **其它同类加固**：`route` / `arp` / `sc` / `ipconfig` 等外部命令全部改成并行读双流 + 超时 Kill；`--ensure` 加 60 秒冷却，避免进程互斥冲突时每两秒派生一个新进程；插件每秒刷新改成复用同一个 HttpClient（以前每小时泄漏上千个连接池，几小时后动态端口耗尽、整机新连接都失败）；hosts 还原等护航任务回话改成真异步，不再卡界面 25 秒。

升级：桌面端「升级」页检查即可，插件会随安装包一起更新。

升级：面板「升级」里检查即可。配置结构版本不变（仍是 schemaVersion 4）。

# ClassroomKit 0.2.10

## 修：保存面板位置跟着鼠标走，先挪指针再按 Ctrl+S

ClassInX 的「保存和分享板书」对话框和「保存至本地」面板，位置取决于**按下 Ctrl+S 那一刻鼠标在哪**。老师是从屏幕右下角托盘点的保存，指针还停在底部，于是两条窗口一路贴到任务栏，勾选框和「保存」按钮被挡住/点不到。

- 现在按 Ctrl+S 之前，先把虚拟鼠标指针移到屏幕上方中间（x 居中、y 约 1/6 屏高），停 180ms 再按。
- 对话框底边仍超出屏幕时，会再把对话框往上拖一段，面板跟着上移。
- 点「保存至本地」图标前指针也先回到对话框上方，面板尽量往上弹。
- 保存过程中不弹托盘气泡，结束才给结果提示。
