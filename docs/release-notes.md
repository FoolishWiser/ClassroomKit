# ClassroomKit 0.2.8

## 修：保存板书被自家通知挡住

- 点「保存 ClassInX 板书」后不再弹「正在保存板书」托盘气泡。这个气泡固定在屏幕右下角，正好压在 ClassInX「保存至本地」面板的勾选框和「保存」按钮上，点击会先落到气泡上，看起来像“点了没反应”。
- 保存结束（成功或失败）仍会给一次结果气泡，不影响反馈。
- 配合 0.2.7 的视觉定位：绿色勾选框行、「保存」按钮都按屏幕实际像素找，面板高度随路径变化也能认出。

## 升级流程重做：静默 + 加速

- 安装改为完全静默：`msiexec /qn /norestart REBOOT=ReallySuppress`，不再弹带进度条的安装界面，只剩一次管理员授权。
- 下载改为分段并发：按 8 MB 切片、最多 6 路同时下载，再合并校验 sha256。学校网络单连接只有几十 KB/s 时能明显提速；服务器不支持 Range 时自动回退单连接。
- 旧版本安装包继续在启动时自动清理，`update` 目录最多留一个待安装包。

## 升级方式

面板「升级 → 检查更新 → 下载并升级」，或托盘「检查更新…」，或直接安装 `ClassroomKit-0.2.8-x64.msi`。安装过程会弹一次管理员授权，之后无界面，热点会中断几秒。
