# ClassroomKit 0.5.0

从「网页控制面板」升级成**桌面端软件**。守护、插件、网页面板都还在，只是日常操作换成了原生窗口。

- **主界面**：双击 `ClassroomKit.Agent.exe`（或开始菜单「ClassroomKit 助手」）打开，左侧六页——概览 / 热点 / 课表与板书 / 升级 / 自检与日志 / 设置。托盘图标左键、右键都弹菜单；关窗口默认收进托盘，守护照常跑。
- **界面会记住你**：窗口大小与位置、最后停留的页面、主题（跟随系统 / 浅色 / 深色）都存进配置，下次打开原样。
- **课表与板书页**直接改提前量、弹窗秒数、超时动作、是否只在 ClassInX 运行时提醒、是否按课表改名和命名模板，右侧实时预览保存后的文件名；还能预览提醒窗、立即保存板书。
- **自检与日志页**：一键自检按「正常 / 注意 / 有问题」着色，旁边直接看最近日志；设置页能装护航任务、刷新/还原 hosts、打开网页面板。
- **保存板书、安装护航任务改到后台跑**，不再把界面卡住；护航任务需要管理员时弹一次 UAC。
- **网页面板保留**：`http://127.0.0.1:36037/?t=令牌` 仍可手机或另一台电脑访问（设置页有入口）。
- 配置结构升到 schemaVersion 5：新增 `ui` 段（关窗收托盘、启动最小化、窗口几何、最后页面、主题），旧配置自动补默认值，SSID / 密码 / 令牌 / 课表设置都不动。
- 插件随版本号一起发 0.5.0，功能与 0.4.3 相同。

升级：桌面端或面板「升级」里检查即可，也可以直接装新 MSI。托盘菜单、命令行动词与 HTTP API 都向后兼容。

## 历史：0.4.3

功能 + 修复版。三件事：

- **课表联动可按科目定向**：面板「课表」卡片和插件设置页新增「生效科目」（逗号分隔，如 `物理`，留空 = 所有科目）。只有这些课的课前提醒会弹，自动保存板书由提醒触发，所以也就等于「只听这几门课的」。匹配很宽松：去空格、不区分大小写，「物理」也能命中课表里的「物理实验」「物理/实验」。板书文件名**不受影响**，仍按课表科目命名——临时手动保存照样能存成正常的名字。
- **修好「预览冲突提示窗」点了没反应**：以前预览必失败，日志里只有一句「预览冲突窗失败：Control does not support transparent background colors.」。根因是冲突窗里的倒计时条是自绘控件，WinForms 不允许这类控件设透明底色，构造弹窗时直接抛异常。现在改成用弹窗同色填充（视觉等价、任何控件都接受），卡片、关闭键、倒计时条、复选框一起改掉。
- **提醒窗按钮不再露灰角**：课前提醒窗的按钮四角原来是系统灰，现在跟着弹窗底色走。
- **失败时看得见**：冲突窗/提醒窗再出问题，日志会写完整堆栈，托盘还会弹气泡提示，不会再「点了没反应也不知道为什么」。

升级：面板「升级」里检查即可。配置结构版本不变（仍是 schemaVersion 4），旧配置没有「生效科目」时按「所有科目」处理，行为与 0.4.2 完全一致。

## 历史：0.4.2

小补丁，只修一处观感问题：

- **刷新 hosts 不再误报失败**：守护是普通权限运行时写不了 hosts，会把请求投给 SYSTEM 护航任务。以前这里干等 25 秒再报「护航服务没有响应」，可实际上请求已经躺在信箱里、5 分钟内就会写进去。现在直接回「已提交给护航任务，最多 5 分钟内写入」，也不再因为这次「没等到回执」而跳过 DNS 刷新与连通性校验。

升级：面板「升级」里检查即可。配置结构版本不变（仍是 schemaVersion 4）。

## 历史：0.4.1

补丁版，修三个用起来卡手的地方：

- **课表终于能进守护**：插件读令牌时只认 `Token`，而守护配置里是 camelCase 的 `token`，于是一直 401。现在大小写不敏感；设置页还会显示「令牌来源（插件设置 / 已读取守护配置 / 空）」，401 时排错不用猜。
- **插件「概览」能打开**：`.cipx` 里补上 `README.md` 和 `icon.png`，清单声明 `readme`/`icon`，ClassIsland 里不再报缺少自述文件。
- **护航任务真的会跑**：任务新增定时触发（每 5 分钟）并在注册后立即运行一次；守护用「心跳文件」判断它是否活着，不再因为普通权限查不到 SYSTEM 任务就误报「没有找到护航任务」。面板 hosts 卡新增「安装护航任务」按钮，只需一次管理员授权，不用再敲 `--install-service`。

升级：老版本在面板「升级」处即可看到本版。配置结构版本不变（仍是 schemaVersion 4），已有设置原样保留。

## 历史：0.4.0

正式版。这一版把定位从「教室热点」扩成「教室一体机助手」：热点退到基础能力，课前与板书成为主角。

- **上课前提醒保存板书**：ClassIsland 课表离下一节还有 5 分钟（可调 1–30）时弹一次提醒窗；30 秒超时默认「保存，但不关 ClassInX」，鼠标悬停暂停，键盘 1/2/3 直接选。
- **板书按上一节课改名**：存成 `数学_2026-11-14_10-05.png`；模板可改（`{科目} {日期} {时间} {节次} {周几}`），同名自动补 `_2`。
- **ClassIsland 2.1 插件改名为「ClassroomKit 助手」并新增课表桥**：把课表快照推给守护，设置页能看课表联动状态，新增「保存板书」行动；热点逻辑仍在独立守护进程里。
- **面板重做**：课表卡置顶，新增一键自检（11 项检查 + 下一步建议）与「重置面板令牌」，热点相关卡片下移、文案改成辅助工具口径。
- **README 重写**：按「课表 / 板书 / 热点 / hosts / 升级」重新组织，讲清哪部分必须在守护进程、哪部分必须在插件里。
- **两处使用体验修正**：自动安装不再限定凌晨（`update.installWindow` 默认留空 = 全天，只要没有设备连着热点就装）；GitHub 加速改为**全天生效**（直连也走加速记录，写后仍校验、不通自动还原）。

升级：老版本在面板「升级」处即可看到本版；自动安装需开启 `update.autoInstall`。配置自动迁移到 schemaVersion 4：只补新字段、把 0.3.x 的默认安装窗口（02:00-05:00）改成不限，SSID / 密码 / 令牌和用户自填的窗口都不变。

## 历史：0.3.0

正式版。相对 0.2.10 的主要变化：

- **ClassIsland 2.1 插件**：装 `.cipx` 后可在 ClassIsland 里看热点状态、在上课/下课时自动开关热点；热点逻辑仍在独立守护进程里，ClassIsland 崩了不影响上网。
- **热点默认值跟机器走**：全新安装时 SSID = 计算机名、密码每机随机 8 位，换教室不再粘旧热点；已有配置原样保留。
- **GitHub 访问加速（全天生效）**：有可用记录就写进 hosts，直连也走加速，按刷新间隔自动更新（由 SYSTEM 护航任务执行），写完校验，仍不通自动还原。
- **全程静默升级**：由 SYSTEM 护航任务用 `msiexec /qn` 安装，不弹 UAC；支持开机自检；自动安装不再限定凌晨（留空=全天，仅要求没有设备连着热点）。
- **板书冲突提示窗重做**：圆角卡片、真实应用图标、高 DPI 缩放、键盘 1–4、倒计时悬停暂停、今天不再提醒。

升级：老版本在面板「升级」处即可看到本版；自动安装需开启 `update.autoInstall`。配置自动迁移到 schemaVersion 2，SSID / 密码 / 令牌不变。

## 历史：0.3.0-pre.3

## 新：全程静默升级（不弹 UAC）

- 下载完把 MSI 投给 SYSTEM 护航任务 `ClassroomKit-Service`，由它以 `msiexec /qn /norestart` 安装；护航任务先停掉用户态守护（否则替换不了 exe），装完再把新版本拉回用户会话。
- 面板「下载并升级」不再弹 UAC、不再出现安装窗口；没装护航任务时才退回管理员授权安装。
- 排队的代价：护航任务每 5 分钟醒一次（原来是 15 分钟），点升级后最多等 5 分钟；点「立即执行」那一次会马上跑。

## 新：开机自检与自动安装

- 启动 90 秒后自检一次（`update.checkOnBoot`），之后每 `update.checkIntervalHours` 小时查一次（默认 6，0 = 只手动）。
- `update.autoInstall` 默认关闭；打开后只要**没有设备连着热点**（`update.installWithClients`）就自己装 —— 上课中不会断学生的网。时间窗默认不限（`update.installWindow` 留空）；需要避开上课才填 `23:00-06:00` 这类窗口。
- 面板「升级」卡片新增这四个开关/输入框与状态提示；API 新增 action `update-config`。

## 改：升级状态

- `/api/update` 增加 `silent`、`checkOnBoot`、`autoInstall`、`installWithClients`、`installWindow`、`installWindowText`、`checkIntervalHours`、`serviceInstalled`；静默安装时状态文案是「正在后台静默安装（无需操作）…」。

## 历史：0.3.0-pre.2

## 新：GitHub 访问加速（hosts 护航）

- 守护按刷新间隔更新 hosts，**全天生效**（直连也走加速）；写完立即校验，还是不通就自动还原。
- 从公开 hosts 源取候选，按 443 端口实测时延挑最快的 IP；区块置顶、保留原文件内容与 CRLF/LF，写前备份到 `hosts.classroomkit-original`。
- 写 hosts 需要管理员：普通权限下投递给 **SYSTEM 护航任务** `ClassroomKit-Service`（开机 1 分钟后、每 15 分钟醒一次 —— pre.3 起改为每 5 分钟，动作 `--service-tick`），守护最多等 25 秒。
- 面板新增「GitHub 访问加速」卡片；命令行 `--hosts-status` / `--hosts-refresh` / `--hosts-restore` / `--install-service`；API `GET /api/hosts` 与两个 action。
- 详见 [GitHub-加速.md](GitHub-加速.md)。

## 改：卸载与安装

- MSI 安装时一并注册护航任务，卸载时一并删除；绿色版 `install.ps1` 同样注册。
- 配置结构版本升到 2：旧 `config.json` 自动补 `hosts` 段（只盖章，不改任何已有值）。

## 历史：0.3.0-pre.1

第一版预发布（开发期用 `-pre.N` 标记，现已并入 0.3.0）。内核照旧独立，ClassIsland 这一层从「零代码自动化」升级成**真正的插件**。

## 新：ClassIsland 2.1 插件（`.cipx`）

- 设置页「ClassroomKit 热点」：状态、SSID、密码、已连设备数、上联网卡、守护版本；一键启动/关闭/修复连接上限/打开控制面板。
- 主界面组件：一行显示 `热点 ON · SSID · 3/10`。
- 自动化行动：「开启教室热点」「关闭教室热点」，上下课自动开关。
- 插件只是薄壳，通过 `127.0.0.1:36037` 指挥独立守护进程 —— ClassIsland 崩了、晚启动、升级中，热点都不受影响。1.6/1.7 的零代码接法继续可用。

## 新：默认值按机器生成（防跨教室漫游）

- 全新安装的热点名默认 = **这台电脑的计算机名**；密码 = 每机随机 8 位。
- 老机器升级**不动**已有 SSID/密码；面板会出现提示条「热点名还是旧的默认值」，点一下即可改成电脑名。
- 热点名超过 32 字节（约 10 个汉字）会按 UTF-8 安全截断，不会切坏半个汉字。

## 改：版本与构建

- 版本号收敛到 `Directory.Build.props` 单一来源；插件 manifest 版本由 CI 同步并校验。
- 升级比较改成 SemVer 预发布规则（`pre.2` < `pre.10`、正式版 > 预发布、忽略 `+build`）。
- CI 一次产出 MSI / zip / cipx 三个资产；正式版不带 `-`，Release 都是正式版。

# ClassroomKit 0.2.10

## 修：保存面板位置跟着鼠标走，先挪指针再按 Ctrl+S

ClassInX 的「保存和分享板书」对话框和「保存至本地」面板，位置取决于**按下 Ctrl+S 那一刻鼠标在哪**。老师是从屏幕右下角托盘点的保存，指针还停在底部，于是两条窗口一路贴到任务栏，勾选框和「保存」按钮被挡住/点不到。

- 现在按 Ctrl+S 之前，先把虚拟鼠标指针移到屏幕上方中间（x 居中、y 约 1/6 屏高），停 180ms 再按。
- 对话框底边仍超出屏幕时，会再把对话框往上拖一段，面板跟着上移。
- 点「保存至本地」图标前指针也先回到对话框上方，面板尽量往上弹。
- 保存过程中不弹托盘气泡，结束才给结果提示。

## 升级方式

面板「升级 → 检查更新 → 下载并升级」，或托盘「检查更新…」，或直接安装 `ClassroomKit-0.2.10-x64.msi`。升级走静默安装（`msiexec /qn`）+ 分段并发下载，只剩一次管理员授权。
