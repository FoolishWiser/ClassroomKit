# ClassroomKit 0.2.9

## 修：保存面板弹得太低、被遮挡

ClassInX 的「保存至本地」面板会贴着对话框/鼠标位置往下弹。学校一体机 150% 缩放下，保存对话框本身就有 672 高，底边已经超出 1080 的屏幕，「保存」按钮和勾选框贴着任务栏，也容易被右下角通知压住。

- 点「保存至本地」前，如果对话框底边超出屏幕，先抓住标题栏把它往上拖到完整可见，面板会跟着上移。
- 点图标前把鼠标先移到对话框上方停一下，让面板尽量往上弹。
- 保存过程中不再弹「正在保存板书」托盘气泡（0.2.8 起），结束才给结果提示。

## 升级（0.2.8 起）

- 静默安装：`msiexec /qn`，没有安装界面，只剩一次管理员授权。
- 分段并发下载：8 MB 分片、最多 6 路，合并后校验 sha256；不支持 Range 时自动回退单连接。

## 升级方式

面板「升级 → 检查更新 → 下载并升级」，或托盘「检查更新…」，或直接安装 `ClassroomKit-0.2.9-x64.msi`。
