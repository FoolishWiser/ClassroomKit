# ClassroomKit 0.6.7

0.6.7 让板书冲突处理从「只会弹窗」变成可以按科目记住老师的习惯，顺手修掉两个误报与误导。

- **新增「高级」页（按科目记住习惯）**：侧边栏多一页「高级」，提示「熟知老师习惯再开启」。给每门课选一个习惯软件（ClassInX / 希沃白板 / WPS）和一个「理解程度」：理解 = 冲突时照旧弹窗交给老师；不理解 = 老师打开习惯软件时，静默关掉另一款。开启习惯模式后，没设置习惯的科目不做任何处理（不弹窗也不关软件）。
- **只在老师打开习惯软件时让路**：老师先开着习惯软件、后来又手动打开另一款，不做处理也不弹窗；程序启动时已经开着的软件同样不关，避免刚开机就关掉老师准备好的课件。
- **希沃 PPT 助手不再被当成白板**：希沃课堂助手 / PPT 小助手（`SeewoIwbAssistant` 这类进程）名字里带 seewo，以前被算成希沃白板悬浮窗，导致只用 WPS + ClassInX 的课也弹冲突窗。现在这类助手进程与标题不参与冲突判定，最小化的窗口直接忽略；仍误报可在 `conflict.ignoreProcesses` 里按进程名或标题片段兜底排除。
- **升级进度条不再一点就满**：以前把 0–100 的百分数写进 `Maximum=1` 的进度条，第一次回调就满格。现在内部统一 0–1、页面按百分比显示；只有「下载中」和「已下载」才显示进度条，其它阶段只显示阶段文字。

## 历史：0.6.6

0.6.6 把 2026-11-17 那台希沃一体机热点故障的教训做成守护能力：先确认系统真的把热点开起来了再报「已开」；报开着却长时间收不到任何包时给出可执行的提示，也可以一键复位网卡。

- **启动后等系统确认**：以前 `StartAsync` 一返回就报「已开」，而系统还在 InTransition（现场的 8821CU 要 10–30 秒），面板只会显示「未知」；现在最多等 30 秒轮询，进 On 才报开好，否则显示「已发出启动，等待系统就绪」，下一轮继续看。
- **假启动可观测**：热点报 On、零客户端、Wi-Fi Direct 适配器累计收包 5 分钟不涨，日志会提示「可能是假启动」——手机能看到热点却连不上。判断只看客户端数与 AP 收发计数，不要用本机 `netsh wlan show networks`（STA 扫描看不到自己发的热点）。
- **可选的自动复位**：`hotspot.restartAdapterOnIdleNoRx`（默认关）打开后，确认假启动就自动 `Restart-NetAdapter` 并重开热点，15 分钟内最多一次；默认关是因为空教室整夜无人连接时收包同样是 0，自动复位会打断希沃传屏这类 Wi-Fi Direct 应用。
- **应急命令行**：`ClassroomKit.Agent.exe --restart-wifi` 复位无线网卡再重开热点（需要管理员），现场不用再手点设备管理器。
- **密码被系统改回去会提醒**：10 分钟内配置被改回 3 次时告警——Windows「移动热点」里还开着一份设置，把两边密码与名称改成一致即可（那台 888 连不上的第一原因）。

## 历史：0.6.5

0.6.5 把升级与 ClassIsland 插件更新里剩下的坑补掉：不会再把「正在安装」冲掉，无人值守时不再弹 UAC，旧插件包也不会把新插件降级。

- **静默安装不会被「检查更新」打断**：以前升级期间点一次检查，状态就从「正在安装」变成「检查中」，20 分钟看门狗再也对不上，面板可能永远停在「正在安装」；现在安装期间检查直接沿用原状态。
- **无人值守不再卡在 UAC**：没装护航任务的机器在凌晨自动升级时，以前会启动提权进程、把调用线程永远挂在安全桌面上；现在先判断有没有可交互桌面，没有就提示到电脑前手动升级。
- **重复点升级不会互相覆盖**：已经在安装中再点一次只提示等待；升级页三个按钮共用一把锁，连点两下不会并发检查 / 下载 / 安装。
- **插件包不会再「装一半」或降级**：`manifest.yml` 改成最后写（dll 被占用时目录里仍是旧版本号，下次继续重试）；没有写入权限单独提示且不再排进待装队列；待安装的包不比本机新就直接清掉；临时解压目录挪到 `update\tmp`，不再落在 `Plugins` 里被 ClassIsland 当成第二个插件；手动更新与巡检补装共用一把插件安装锁。
- **护航任务超时对齐**：计划任务超时从 10 分钟放宽到 30 分钟，不会在 msiexec 还在装的时候把任务杀掉；schtasks 查询失败也不再当成「没装」缓存 30 秒，避免静默安装退化成弹 UAC。

升级：桌面端「升级」页检查即可，插件会随安装包一起更新。

## 历史：0.6.4

0.6.4 是一次「防假死」加固：把几处会卡住线程、卡住整机输入的地方改掉，功能与界面不变。

- **每秒一次的 schtasks 查询停掉了**：面板以前每秒钟都去查一次「护航任务」状态，背后是启动 `schtasks.exe` 并同步读到它退出；一旦 schtasks 变慢（机器忙、杀软扫描），调用线程就永久挂着，面板停止刷新、线程池被抽干，整机看起来像死机。现在结果缓存 30 秒，并且先等进程退出再读输出、5 秒超时直接杀掉。
- **后台不再弹 UAC**：网页 / HTTP 接口与巡检路径调用「修复客户端上限」时不再尝试提权弹框；没有可交互桌面就返回一句说明，到电脑前手动点一次即可。所有提权等待都带 120 秒超时，超时杀掉进程。
- **不再每分钟全盘扫 ClassIsland**：机器上没装 ClassIsland 时，以前每分钟都会重新扫一遍用户目录与 Program Files（深度 4、每根 4000 个目录），机械盘和 OneDrive 上足以把磁盘队列打满。现在空结果也走缓存，连续 3 次为空退避到 30 分钟，扫描深度降到 3、每根 1500 个目录、单次 8 秒预算。
- **一次异常不会带走键盘鼠标**：切前台、拖拽、Ctrl+S 这些注入动作全部加了 try/finally，异常或中断也会把 ALT 与鼠标键抬起来；守护启动时还会先做一次「释放所有注入按键」。以前中断后整个桌面像死机，重启本程序也不恢复。
- **冲突提示窗不再冻住界面**：悬停暂停最多延长 15 秒；关进程的操作挪到后台线程，关窗后界面不会再「未响应」五到十几秒；托盘询问框 5 秒没反应就按「不升级」处理。
- **日志改成批量落盘**：以前每条日志同步写盘并持全局锁，磁盘一慢所有调用方一起等。现在先进内存队列，由后台线程每 500 毫秒或满 200 条刷一批，退出时兜底写完。
- **HTTP 面板加了连接上限**：最多同时处理 16 个连接，accept 异常后先退避 200 毫秒，不再空转吃满一个核。
- **其它同类加固**：`route` / `arp` / `sc` / `ipconfig` 等外部命令全部改成并行读双流 + 超时 Kill；`--ensure` 加 60 秒冷却，避免进程互斥冲突时每两秒派生一个新进程；插件每秒刷新改成复用同一个 HttpClient（以前每小时泄漏上千个连接池，几小时后动态端口耗尽、整机新连接都失败）；hosts 还原等护航任务回话改成真异步，不再卡界面 25 秒。

升级：桌面端「升级」页检查即可，插件会随安装包一起更新。

补丁版，修三个用起来卡手的地方：

- **插件「概览」能打开**：`.cipx` 里补上 `README.md` 和 `icon.png`，清单声明 `readme`/`icon`，ClassIsland 里不再报缺少自述文件。
- **护航任务真的会跑**：任务新增定时触发（每 5 分钟）并在注册后立即运行一次；守护用「心跳文件」判断它是否活着，不再因为普通权限查不到 SYSTEM 任务就误报「没有找到护航任务」。面板 hosts 卡新增「安装护航任务」按钮，只需一次管理员授权，不用再敲 `--install-service`。

升级：老版本在面板「升级」处即可看到本版。配置结构版本不变（仍是 schemaVersion 4），已有设置原样保留。

# ClassroomKit 0.2.10

## 修：保存面板位置跟着鼠标走，先挪指针再按 Ctrl+S

ClassInX 的「保存和分享板书」对话框和「保存至本地」面板，位置取决于**按下 Ctrl+S 那一刻鼠标在哪**。老师是从屏幕右下角托盘点的保存，指针还停在底部，于是两条窗口一路贴到任务栏，勾选框和「保存」按钮被挡住/点不到。

- 现在按 Ctrl+S 之前，先把虚拟鼠标指针移到屏幕上方中间（x 居中、y 约 1/6 屏高），停 180ms 再按。
- 对话框底边仍超出屏幕时，会再把对话框往上拖一段，面板跟着上移。
- 点「保存至本地」图标前指针也先回到对话框上方，面板尽量往上弹。
- 保存过程中不弹托盘气泡，结束才给结果提示。

## 升级方式

面板「升级 → 检查更新 → 下载并升级」，或托盘「检查更新…」，或直接安装 `ClassroomKit-0.2.10-x64.msi`。升级走静默安装（`msiexec /qn`）+ 分段并发下载，只剩一次管理员授权。
