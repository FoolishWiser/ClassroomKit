## ClassroomKit 0.2.6

### 修好了「ClassInX 最小化时保存板书失败」

学校一体机是 150% 显示缩放（DPI 144），保存对话框实际是 1230×672，而配方是按 96 DPI 的 820×448 量的。旧版点「保存至本地」时没做折算，点偏了，面板根本没打开。

- 所有相对坐标按对话框/面板的**实测尺寸**折算，150% 下自动 ×1.5
- 面板只认「点完之后新出现、尺寸符合预期」的窗口，登录卡片不会再被当成面板
- 提示框、覆盖确认框的尺寸匹配也跟着 DPI 缩放
- 失败时截图更全：对话框、点后全屏、面板、勾选框全屏 + 窗口清单（含 DPI）

### 升级残留

- 启动时清理 `C:\ProgramData\ClassroomKit\update`：已安装版本直接删，其余只留最新一个待安装包，`.part` 临时文件清掉

### 其它

- 单元测试 66 项全过；MSI 与 zip 由 GitHub Actions（windows-latest）构建
- 安装：下载 `ClassroomKit-0.2.6-x64.msi` 双击，或用面板「升级」检查更新
